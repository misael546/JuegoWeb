NEON CORE

An original browser multiplayer tank game built as a software development project. The project combines a GitHub Pages client with a Node.js/WebSocket multiplayer server hosted on Render.

PLAY NEON CORE VIEW SOURCE CODE

Project Architecture

Web Client

HTML5 Canvas, JavaScript, responsive mobile controls, rooms, combat, progression and HUD.

Multiplayer

Real-time WebSocket communication with shared rooms, player lists, PvP damage and respawn.

Server

Node.js server with the ws WebSocket library, deployed online through Render.

Development

The project is maintained in GitHub and is intended as an ongoing software development project.

About the Project

NEON CORE is used to develop and test browser-game networking, real-time state synchronization, gameplay systems, mobile input and web deployment.
